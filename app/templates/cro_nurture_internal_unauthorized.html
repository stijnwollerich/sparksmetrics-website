Unauthorized

The server has a token configured, but the request did not match.

  • Use the exact value of CRO_NURTURE_CRON_TOKEN (or CRO_NURTURE_INTERNAL_DASHBOARD_TOKEN if you set that).
  • Example: /cro-nurture/internal/leads?token=YOUR_SECRET
  • Or header X-Cron-Token: YOUR_SECRET / Authorization: Bearer YOUR_SECRET
  • No spaces or quotes in the URL — if you copy-pasted from .env, avoid trailing spaces (we strip them server-side now).

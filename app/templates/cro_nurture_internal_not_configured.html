No secret configured on the server

The dashboard needs a token in the environment of the running app (not only your local machine if you deploy elsewhere).

  1. In .env on the server, set CRO_NURTURE_CRON_TOKEN to a long random string (same one you use for cron).
  2. Optionally set CRO_NURTURE_INTERNAL_DASHBOARD_TOKEN instead if you want a different secret only for this page.
  3. Restart the app / redeploy so the process picks up the variable.
  4. Open /cro-nurture/internal/leads?token=…

Also ensure CRO_NURTURE_ENABLED=1 so this blueprint is registered.
